# South Africa Code B — Road Signs Quiz

A browser-only study quiz built from the supplied `RTSigns_charts.pdf`.

## Included in v1

- One question at a time
- Official-chart sign crops from sheets 1–2
- Regulatory, warning and information signs represented in the chart
- Two modes: **What does it mean?** and **Identify the code**
- Randomised answer choices
- Immediate feedback and score
- No backend, no framework, no installation

## Run

Open `index.html` directly in a modern browser. No server or installation is required.

## Source note

The meanings in `data/road-signs.json` follow the terminology printed on sheet 5 of the supplied PDF. The images are crops from sheets 1–2. Where the PDF groups multiple sign variants under one description, those variants use the same source description.
